# EM Code Studio — Landing page corporativa

Proyecto de clase: sitio web estático para una empresa ficticia de desarrollo web y sistemas.
Los clientes, documentos y datos mostrados son **inventados** y se usan solo con fines de demostración.

## Qué incluye

- **HTML5 semántico** con secciones de inicio, servicios, portafolio, tecnologías y contacto.
- **CSS3**: variables, Grid/Flexbox, diseño responsive y **modo claro/oscuro** con persistencia en `localStorage`.
- **JavaScript vanilla**: menú móvil, scroll suave, *scroll spy*, efecto *typewriter*, lightbox de proyectos, cursor personalizado y transiciones de intro.
- Animaciones separadas en `animaciones.css` y `animaciones.js`.

## Cómo verlo

No requiere instalar nada. Abre `index.html` en tu navegador.

Si prefieres servirlo localmente:

```bash
python -m http.server 8000
```

Y visita <http://localhost:8000>.
